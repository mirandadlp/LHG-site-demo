# Image list

Every photo the site expects. Put each file in `assets/images/` with exactly this name, then swap its placeholder for an `<img>` (see README → *Swapping in photos*).

Only use photos LHG owns or has licensed. Export JPGs (or WebP) at the suggested size, around 80% quality, ideally under 300 KB each.

Most photos are cropped by the layout with `object-fit: cover`, so keep the subject near the centre. Where one photo is used in several places the shapes are listed; supply the largest.
